A TPU knowledge base is installed at `{{knowledgebase}}/`.
For a public fact about TPU hardware, runtimes or software -- a spec, a
default, a supported version, what a doc says -- ask the tpu-knowledge-base agent
first when it is installed: it quotes the public page and returns the URL to
cite. Do not answer such facts from memory.
For playbooks, the codebase map and the Pallas concept pages, read the
knowledge base's `index.md` and follow its routing; `SCHEMA.md` beside it
defines the page types. Cite the wiki pages each claim relies on; if neither
tpu-knowledge-base nor the knowledge base covers a topic, say so explicitly. The
installed knowledge base is read-only: never edit its pages.
