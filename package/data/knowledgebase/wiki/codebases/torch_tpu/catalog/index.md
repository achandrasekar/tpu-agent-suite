# Module map: torch_tpu @ 6d2a45754b

716 modules, 19064 documentable symbols, 15910 index rows (overloads share a row), 75029 caller edges. The index is tab-separated; grep it by anchor, never read a file whole. Columns: anchor, path, line, kind, rank, hash, callers, citing pages, then signature and doc line in the full profile. Hubs have hundreds of callers and a search tool shows about 50 lines: count first, narrow by directory, end every listing with `head`.
Source links below are permalinks into the repository at the pin, for readers with access to it; do not fetch them. The index rows carry the path, line, signature and doc line, and the citation's link title carries the source location.

```
grep -P '^<path>#<Name>\t' catalog/symbols.tsv                            # one symbol's row
grep -P '[#.]<Name>\t' catalog/symbols.tsv | sort -t$'\t' -k5 -nr | head -20   # by bare name, best first
grep -P '^<dir>/.*#<Name>\t' catalog/symbols.tsv | head -20                    # a name within an area
awk -F'\t' '$2=="<path>"' catalog/symbols.tsv | cut -f1,3,4 | head -40         # everything a module defines
grep -c -P '^<path>#<Name>\t' catalog/edges.tsv                         # how many callers (count first)
grep -P '^<path>#<Name>\t' catalog/edges.tsv | cut -f2 | cut -d/ -f1-2 | sort | uniq -c   # callers by directory
grep -P '^<path>#<Name>\t<dir>/' catalog/edges.tsv | cut -f2 | head -20      # callers in one directory
grep -P '\t<path>#<Name>$' catalog/edges.tsv | cut -f1 | head -20           # what it calls
```
