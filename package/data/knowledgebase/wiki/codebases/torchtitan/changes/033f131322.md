# torchtitan: changes 63e334d5ba → 033f131322

A routing page, not a diff: which subsystems and wiki pages changed between the two pins, and which commits caused it. Follow a hash for the change itself.

This interval is dominated by one upstream rebase (`fa627bf2`, pytorch/torchtitan as of 2026-09-11)
plus TPU recipe and backend work. The rebase flattens activations to one `[T]` token stream (the
TPU lane reshapes back to `[B, L]`), sizes batches in tokens, replaces per-model TP plans with
`ShardingConfig` declarations, makes context parallel a config transform that requires the
`spmd_types` backend, and splits checkpointing, optimizers and data loading into packages. New
model packages: DeepSeek-V4, Kimi K2.7 and K3, Muse Glimmer, Qwen3.6 and Qwen3.8.
