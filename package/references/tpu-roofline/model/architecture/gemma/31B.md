# Gemma4 31B Dense Model Architecture Specification

This document details the architectural parameters, dimension shapes, and operation-level specifications for the Gemma4 31B Dense model. These details are standardized to follow the conventions in [NOTATION.md](../../../NOTATION.md) for conducting roofline performance estimations.

## 1. Global Model Parameters

| Parameter | Symbol | Value | Description |
| :--- | :--- | :--- | :--- |
| **Total Parameters** | - | $\approx 31\text{B}$ | Approximate active parameters. |
| **Layers** | $L$ | 60 | Total transformer layers. |
| **Local Layers** | $L_{\text{local}}$ | 50 | Layers using Local Sliding Window Attention. |
| **Global Layers** | $L_{\text{global}}$ | 10 | Layers using Global Attention (every 6th layer). |
| **Hidden Dimension** | $D$ | 5,376 | Hidden dimension size (model dimension). |
| **FFN Intermediate Dim** | $F$ | 21,504 | Intermediate hidden dimension for SwiGLU FFN. |
| **Query Heads** | $H_q$ | 32 | Number of query heads. |
| **Head Dimension** | $D_h$ | 256 | Dimension size per attention head. |
| **Local KV Heads** | $H_{\text{kv\_local}}$ | 16 | Key/Value heads in local layers (Group size $G = 2$). |
| **Global KV Heads** | $H_{\text{kv\_global}}$ | 4 | Key/Value heads in global layers (Group size $G = 8$). |
| **Sliding Window Size**| $W$ | 1,024 | Attention window for local layers. |

## 2. Layer Structure & Tensor Flow

Each transformer layer contains a Self-Attention block and a SwiGLU Feed-Forward Network (FFN) block. Both blocks are followed by residual connections and normalizations.

```text
[Input: B x S x D]
       |
       +- RMSNorm -> Self-Attention Block -> [Attention Output] -> Add Residual
       |
       +- RMSNorm -> FFN Block (SwiGLU) ----> [FFN Output] -------> Add Residual
       |
[Output: B x S x D]
```

### 2.1. Self-Attention Block Operations
The attention block utilizes Grouped-Query Attention (GQA) sharded via Tensor Parallelism with degree $P$:

1.  **Q Projection (`W_q`):** Projects hidden dimension to local query heads.
    *   **Weight Shape:** `[D, (H_q / P) * D_h]`
2.  **K Projection (`W_k`):** Projects hidden dimension to local key heads.
    *   **Weight Shape (Local):** `[D, max(1, H_kv_local / P) * D_h]`
    *   **Weight Shape (Global):** `[D, max(1, H_kv_global / P) * D_h]`
3.  **V Projection (`W_v`):** Projects hidden dimension to local value heads.
    *   **Weight Shape:** Same as K Projection.
4.  **Attention Core (QK^T and Score * V):**
    *   **QK Phase:** Computes attention matrix.
    *   **AV Phase:** Computes output attention context.
5.  **Output (O) Projection (`W_o`):** Projects attention heads back to hidden dimension.
    *   **Weight Shape:** `[(H_q / P) * D_h, D]`
    *   **Collective:** All-Reduce along the parallel dimension $P$ (typically BF16).

### 2.2. FFN Block Operations (SwiGLU)
The FFN block uses column-parallel gate/up projections and row-parallel down projection:

1.  **FFN Gate Projection (`W_gate`):** Computes the gating activation.
    *   **Weight Shape:** `[D, F / P]`
2.  **FFN Up Projection (`W_up`):** Computes the intermediate activation.
    *   **Weight Shape:** `[D, F / P]`
3.  **Element-wise Gating:** Fuses Gate and Up activations: $\text{swish}(\text{Gate}) \times \text{Up}$.
4.  **FFN Down Projection (`W_down`):** Projects intermediate dimension back to hidden dimension.
    *   **Weight Shape:** `[F / P, D]`
    *   **Collective:** All-Reduce along the parallel dimension $P$ (typically BF16).

## 3. Exact Shapes by Phase (P=2 Example)

Below are the tensor shapes on each device/chiplet for Tensor Parallelism $P=2$:

### 3.1. Prefill Phase ($B=16, S=1024$)
*   **Input / Output Activation `[B * S, D]`:** `[16384, 5376]`.
*   **Q Proj Output `[B * S, (H_q / P) * D_h]`:** `[16384, 4096]` (16 heads on device).
*   **Local K/V Proj Output `[B * S, max(1, H_kv_local / P) * D_h]`:** `[16384, 2048]` (8 heads on device).
*   **Global K/V Proj Output `[B * S, max(1, H_kv_global / P) * D_h]`:** `[16384, 512]` (2 heads on device).
*   **Attention QK Logits:** `[B, H_q / P, S, S]` which is `[16, 16, 1024, 1024]` (fused in SRAM).
*   **Attention Output `[B, S, H_q / P, D_h]`:** `[16, 1024, 16, 256]` $\rightarrow$ Projected to `[16384, 5376]`.
*   **FFN Gate / Up Output `[B * S, F / P]`:** `[16384, 10752]`.
*   **FFN Down Input `[B * S, F / P]`:** `[16384, 10752]`.

### 3.2. Decode Phase ($B=256, S=1$, Context $S_{\text{ctx}}=1524$)
*   **Input / Output Activation `[B * S, D]`:** `[256, 1, 5376]`.
*   **Q Proj Output `[B * S, (H_q / P) * D_h]`:** `[256, 1, 4096]`.
*   **Local K/V Proj Output `[B * S, max(1, H_kv_local / P) * D_h]` (new token):** `[256, 1, 2048]`. (Appended to cache).
*   **Global K/V Proj Output `[B * S, max(1, H_kv_global / P) * D_h]` (new token):** `[256, 1, 512]`. (Appended to cache).
*   **KV Cache Read (QK phase):**
    *   Local `[B, max(1, H_kv_local / P), W, D_h]`:** `[256, 8, 1024, 256]`.
    *   Global `[B, max(1, H_kv_global / P), S_{\text{ctx}}, D_h]`:** `[256, 2, 1524, 256]`.
*   **Attention Output `[B, S, (H_q / P) * D_h]`:** `[256, 1, 4096]`.
*   **FFN Gate / Up Output `[B * S, F / P]`:** `[256, 1, 10752]`.
*   **FFN Down Input `[B * S, F / P]`:** `[256, 1, 10752]`.
