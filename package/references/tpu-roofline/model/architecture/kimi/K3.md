# Kimi K3 Model Architecture Specification

This document details the architectural parameters, dimension shapes, and operation-level specifications for the **Kimi K3** model. These details are standardized to follow the conventions in [NOTATION.md](../../../NOTATION.md) for conducting roofline performance estimations.

## 1. Global Model Parameters

| Parameter | Symbol | Value | Description |
| :--- | :--- | :--- | :--- |
| **Total Parameters** | - | $\approx 2.8\text{T}$ | Total model parameter count ($2,800\text{B}$). |
| **Active Parameters** | - | $\approx 104\text{B}$ | Active parameters computed per token. |

| **KDA Layers** | $L_{\text{kda}}$ | 69 | Layers using Kimi Delta Attention (KDA). |

| **KDA Conv Dimension** | $D_{\text{conv}}$ | 36,864 | Combined channels for Q, K, V Conv1D ($3 \times H \times D_h$). |

## 2. Layer Structure & Tensor Flow

Kimi K3 combines linear attention, latent compression, and sparse mixture-of-experts in an alternating architecture:

*   **Attention Sub-Layers (3:1 Hybrid Interleaving):**
    *   3 KDA layers followed by 1 Gated MLA layer uniform repeating pattern.
    *   **MLA Layers (0-indexed, 24 total):** Indices `{3, 7, 11, 15, 19, 23, 27, 31, 35, 39, 43, 47, 51, 55, 59, 63, 67, 71, 75, 79, 83, 87, 91}` $\cup$ `{92}`. *(The final two layers 91 and 92 are MLA).*
    *   **KDA Layers (0-indexed, 69 total):** All remaining layers (`{0, 1, 2, 4, 5, 6, ..., 90}`).
*   **FFN Sub-Layers:**
    *   **Layer 0:** Dense FFN (SwiGLU / SiTU, intermediate size $F_{\text{dense}} = 33,792$).
    *   **Layers 1 to 92 (92 MoE layers):** Stable LatentMoE with $D \to D_{\text{latent}}$ down-projection ($7,168 \to 3,584$), Top-16 active out of 896 routed experts in **MXFP4**, $D_{\text{latent}} \to D$ up-projection ($3,584 \to 7,168$), and 2 full-rank Shared Experts ($7,168 \to 6,144 \to 7,168$).
*   **Attention Residuals (AttnRes):** Depth-wise learned pseudo-query attention connections pooling preceding layer outputs.

```text
[Input: B x S x D]
       |
       +---> AttnRes Depth Pooling (Learned Softmax over preceding block outputs)
       |
       +---> RMSNorm -> Attention Sub-Layer:
       |                ├── If KDA Layer: QKV Proj -> Conv1D -> Gated Delta Kernel -> Gated RMSNorm -> Out Proj
       |                └── If MLA Layer: Query/KV Comp -> NoPE Attention -> Gated RMSNorm -> Out Proj
       |
       +---> Add Attention Residual
       |
       +---> RMSNorm -> FFN Sub-Layer:
       |                ├── Layer 0: Dense SwiGLU / SiTU MLP (F_dense = 33,792)
       |                └── Layers 1-92: LatentMoE:
       |                                 ├── Down-Proj (7,168 -> 3,584, bf16)
       |                                 ├── Quantile Router -> Top 16 of 896 Experts (MXFP4 weights)
       |                                 ├── Up-Proj (3,584 -> 7,168, bf16)
       |                                 └── 2 Shared Experts (7,168 -> 6,144 -> 7,168, bf16)
       |
       +---> Add FFN Residual
       |
[Output: B x S x D]
```

## 3. Sub-Component Operations & Tensor Shapes

### 3.1. Kimi Delta Attention (KDA) Sub-Layer (69 Layers)

Refer to the [KDA Roofline Skill](../../common/attention/kda/kda.md) for full operational formulas.

1.  **QKV Projections (`q_proj`, `k_proj`, `v_proj`):**
    *   Projects hidden dimension $D \to H_q D_k + H_s D_k + H_s D_v$ ($7,168 \to 36,864$).
    *   Weight Shapes: $W_q$ `[7168, 12288]`, $W_k$ `[7168, 12288]`, $W_v$ `[7168, 12288]`.
    *   FLOPS: `2 * B_local * S * 7168 * 36864`.
2.  **Decay, Beta, and Gate Projections:**
    *   **Decay Gate ($\alpha$ / $g_{\text{raw}}$ - Low-Rank):** Down `[7168, 128]`, Up `[128, 12288]`.
        *   FLOPS: `2 * B_local * S * 7168 * 128 + 2 * B_local * S * 128 * 12288`.
    *   **Beta Write Rate ($\beta$):** Proj `[7168, 96]`. FLOPS: `2 * B_local * S * 7168 * 96`.
    *   **Output Gate ($g$):** Proj `[7168, 12288]`. FLOPS: `2 * B_local * S * 7168 * 12288`.
3.  **Causal Depthwise 1D Convolution:**
    *   $D_{\text{conv}} = 36,864$, $K_{\text{conv}} = 4$, SiLU activation.
    *   FLOPS: `2 * B_local * S * 36864 * 4`.
    *   Decode Cache: `[B_local, 3, 36864]` in `bf16`.
4.  **Q/K Normalization & Key L2 Normalization:**
    *   Per-head RMSNorm on Q and K, L2 normalization on K ($k / \|k\|_2$).
5.  **Core Gated Delta Recurrent Kernel:**
    *   **Prefill Mode (Chunk-wise $C=64$):** Causal Gram matrix solve $(I + G)E = V - U_{\text{prev}}S_{n-1}$, intra-chunk attention, and inter-chunk boundary state updates.
    *   **Decode Mode ($S=1$):** Autoregressive recurrent step-by-step update on persistent state matrix $S \in \mathbb{R}^{96 \times 128 \times 128}$ in **`float32`** (4 bytes/element, $\approx 6.29\text{ MB}$ per sequence per layer).
        *   FLOPS per decode step: `7 * B_local * 96 * 128 * 128` $\approx$ `11.01 * B_local MFLOPS`.
6.  **Gated RMSNorm:** Headwise RMSNorm modulated by sigmoid output gate: $o = \text{sigmoid}(g) \odot \text{RMSNorm}(u)$.
7.  **Output Projection (`out_proj`):**
    *   Projects $H_q D_v \to D$ ($12,288 \to 7,168$). Weight: `[12288, 7168]`.
    *   FLOPS: `2 * B_local * S * 12288 * 7168`.
    *   Tensor Parallelism: Row-parallel sharded with an **All-Reduce** across the TP group.

### 3.2. Gated NoPE Multi-Head Latent Attention (MLA) Sub-Layer (24 Layers)

Refer to the [Gated MLA Roofline Skill](../../common/attention/gated_mla/gated_mla.md) for full operational formulas.


1.  **Query Compression & Projection:**
    *   Down-projection: $W_{DQ}: [D, D_{c,q}] = [7168, 1536]$. FLOPS: `2 * B_local * S * 7168 * 1536`.
    *   Up-projection: $W_{UQ}: [1536, H_q \times D_{h,qk}] = [1536, 96 \times 192 = 18432]$. FLOPS: `2 * B_local * S * 1536 * 18432`.
2.  **KV Latent Compression:**
    *   Down-projection: $W_{DKV}: [D, D_c + D_r] = [7168, 512 + 64 = 576]$. FLOPS: `2 * B_local * S * 7168 * 576`.
    *   **KV Cache Footprint:** Stores 576 elements (`bf16`, 1,152 Bytes) per token per layer.
3.  **Core Attention (NoPE MLA):**
    *   Computes attention using weight absorption (matrix associativity) directly on the 512-dim latent space and 64-dim shared decoupled space.
    *   Prefill FLOPS (Flow B with Weight Absorption):
        *   QK Phase: `2 * B_local * S^2 * H_q_local * (D_c + D_r)`.
        *   AV Phase: `2 * B_local * S^2 * H_q_local * D_c`.
        *   V Up-Projection: `2 * B_local * S * D_c * H_q_local * D_v`.
4.  **Output Gating & RMSNorm:**
    *   Full-rank gate projection: $W_g: [7168, 12288]$. FLOPS: `2 * B_local * S * 7168 * 12288`.
    *   Attention output scaled by $\text{sigmoid}(g)$.
5.  **Output Projection (`out_proj`):**
    *   Projects $H_q D_v \to D$ ($12,288 \to 7,168$). Weight: `[12288, 7168]`.
    *   FLOPS: `2 * B_local * S * 12288 * 7168`. Row-parallel with TP **All-Reduce**.

### 3.3. Dense FFN Sub-Layer (Layer 0 Only)

Refer to the [FFN Roofline Skill](../../common/ffn/ffn.md) for full operational formulas.

1.  **Gate / Up Projection (`W_gate`, `W_up`):**
    *   Projects $D \to 2 \times F_{\text{dense}}$ ($7,168 \to 2 \times 33,792 = 67,584$).
    *   FLOPS: `4 * B_local * S * 7168 * 33792`.
2.  **Activation:** SiTU-GLU / SwiGLU with soft-clamping.
3.  **Down Projection (`W_down`):**
    *   Projects $F_{\text{dense}} \to D$ ($33,792 \to 7,168$).
    *   FLOPS: `2 * B_local * S * 33792 * 7168`.
    *   Tensor Parallelism: Row-parallel with TP **All-Reduce**.

### 3.4. Stable LatentMoE Sub-Layers (Layers 1 to 92, 92 Layers Total)

Refer to the [LatentMoE Roofline Skill](../../common/latent_moe/latent_moe.md) for full operational formulas.


1.  **Latent Down-Projection (`W_down_lat`):**
    *   Compresses hidden states $D \to D_{\text{latent}}$ ($7,168 \to 3,584$, `bf16`).
    *   Weight Shape: `[7168, 3584]`.
    *   FLOPS: `2 * B_local * S * 7168 * 3584`.
2.  **Quantile Router:**
    *   Computes routing scores for 896 experts and selects the top $K = 16$ experts per token.
    *   Weight Shape: `[7168, 896]`.
    *   FLOPS: `2 * B_local * S * 7168 * 896`.
3.  **Routed Experts ($E_{\text{routed}} = 896, K = 16$, MXFP4 Weights):**
    *   Each token routes its 3,584-dim latent vector to 16 active experts.
    *   **Expert Gate/Up Projection (`W1`, `W3`):** Projects $D_{\text{latent}} \to 2 \times F_{\text{expert}}$ ($3,584 \to 2 \times 3,072 = 6,144$).
        *   Weight Shape (per expert): `[3584, 6144]` (stored in **MXFP4**, 0.5 Bytes/weight).
        *   FLOPS (16 active experts): `16 * 4 * B_local * S * 3584 * 3072` = `64 * B_local * S * 3584 * 3072`.
    *   **Activation:** SiTU-GLU soft-clamping ($\beta_1 = 4.0, \beta_2 = 25.0$).
    *   **Expert Down Projection (`W2`):** Projects $F_{\text{expert}} \to D_{\text{latent}}$ ($3,072 \to 3,584$).
        *   Weight Shape (per expert): `[3072, 3584]` (stored in **MXFP4**, 0.5 Bytes/weight).
        *   FLOPS (16 active experts): `16 * 2 * B_local * S * 3072 * 3584` = `32 * B_local * S * 3072 * 3584`.
    *   **Total Routed Expert FLOPS:** `96 * B_local * S * 3584 * 3072` $\approx$ `1.057 * B_local * S TFLOPS`.
    *   **Memory Bandwidth Scaling:** Routed expert weights are quantized to **MXFP4 (4-bit, 0.5 Bytes/param)**. Memory transfer bandwidth must use 0.5 Bytes per weight parameter.
4.  **Latent Up-Projection (`W_up_lat`):**
    *   Projects combined latent output back to model dimension $D_{\text{latent}} \to D$ ($3,584 \to 7,168$, `bf16`).
    *   Weight Shape: `[3584, 7168]`.
    *   FLOPS: `2 * B_local * S * 3584 * 7168`.
5.  **Shared Experts ($E_{\text{shared}} = 2$, Always Active, Full Dimension $D = 7,168$, `bf16`):**
    *   Operates unconditionally on the uncompressed $D = 7,168$ hidden state in `bf16`.
    *   Combined intermediate size: $F_{\text{shared}} = 2 \times 3,072 = 6,144$.
    *   **Shared Gate/Up Projection:** `[7168, 2 * 6144]`. FLOPS: `4 * B_local * S * 7168 * 6144`.
    *   **Shared Down Projection:** `[6144, 7168]`. FLOPS: `2 * B_local * S * 6144 * 7168`.

### 3.5. Attention Residuals (AttnRes)

*   Learned depth-wise Softmax attention connection across preceding layer checkpoints.
*   Checkpoints placed at regular layer intervals (e.g., layers `{0, 12, 24, ..., 84}`).
*   Compute overhead is negligible (<2% extra FLOPs), with $\approx 115\text{ KB}$ active activation memory per token.

## 4. Precision, Quantization & Memory Footprint

### 4.1. Data Types

*   **Routed MoE Experts:** **`MXFP4`** (4-bit microscopic scaling, 0.5 Bytes per parameter).
*   **KDA Recurrent State Cache ($S$):** **`float32`** (4 Bytes per element) for numeric stability of the recursive delta rule.
*   **KDA Conv1D State Cache:** **`bfloat16`** (2 Bytes per element).
*   **MLA KV Latent Cache:** **`bfloat16`** (2 Bytes per element).
*   **Remainder (Attention, Shared Experts, Projections, Embeddings, Activations):** **`bfloat16`** (2 Bytes per element).

### 4.2. Per-Sequence State Memory Footprint (Serving / Inference)

For a single sequence of context length $S$:

1.  **KDA Recurrent State (69 Layers):**
    $$\text{Memory}_{\text{KDA State}} = 69 \times H_s \times D_k \times D_v \times 4\text{ Bytes} = 69 \times 96 \times 128 \times 128 \times 4 \approx \mathbf{434.1\text{ MB per sequence}}$$
    *(Constant $O(1)$ memory with respect to sequence length $S$).*
2.  **KDA Conv1D Cache (69 Layers):**
    $$\text{Memory}_{\text{KDA Conv}} = 69 \times (K_{\text{conv}} - 1) \times D_{\text{conv}} \times 2\text{ Bytes} = 69 \times 3 \times 36,864 \times 2 \approx \mathbf{15.26\text{ MB per sequence}}$$
3.  **MLA KV Latent Cache (24 Layers):**
    $$\text{Memory}_{\text{MLA KV}} = 24 \times S \times (D_c + D_r) \times 2\text{ Bytes} = 24 \times S \times 576 \times 2 = \mathbf{27.65\text{ KB} \times S\text{ per sequence}}$$
    *(For $S = 131,072$ context tokens, MLA KV Cache is $\approx 3.62\text{ GB per sequence}$).*

## 5. Parallelism Strategies & Distributed Scaling

### 5.1. Tensor Parallelism (TP)

When TP degree is `TP` (e.g., `TP = 32` or `TP = 16`):

*   **KDA Heads Sharding:** $H_{q,\text{local}} = H_q / \text{TP} = 96 / \text{TP}$, $H_{s,\text{local}} = H_s / \text{TP} = 96 / \text{TP}$.
*   **KDA Conv Sharding:** $D_{\text{conv},\text{local}} = 36,864 / \text{TP}$.
*   **MLA Heads Sharding:** $H_{q,\text{local}} = 96 / \text{TP}$. KV latent vector ($576$ elements) is broadcasted/shared.
*   **Attention Output Projections:** Row-parallel sharded, requiring an **All-Reduce** collective of size $M = B_{\text{local}} \cdot S \cdot D \times \text{bytes}$.
*   **MoE Shared Experts:** Intermediate dimension sharded as $F_{\text{shared}} / \text{TP} = 6,144 / \text{TP}$, requiring an **All-Reduce** on down-projection.

### 5.2. Expert Parallelism (EP)

When EP is enabled across $P_{\text{ep}}$ devices:

*   896 routed experts are partitioned evenly ($E_{\text{local}} = 896 / P_{\text{ep}}$ experts per device).
*   Tokens are dispatched via an **All-to-All** collective before expert computation (payload $M = B_{\text{local}} \cdot S \cdot K \cdot D_{\text{latent}} \times \text{bytes}$) and gathered via an **All-to-All** token combine collective.
