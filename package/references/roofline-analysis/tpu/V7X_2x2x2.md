# TPU v7x — `2x2x2` slice constants

The slice has **8 chips, each with 2 chiplets = 16 cores (JAX devices) total**. `2x2x2` names the
slice in **chips**; the tables below are in **cores**. Terminology follows [`V7X.md`]({{reference:roofline-analysis/tpu/V7X.md}}) §1.

---

## 1. Per-core constants (per chiplet / JAX device)

| Hardware Metric | Symbol | Value | Unit / Note |
| --- | --- | --- | --- |
| FP8 / FP4 Peak Compute | $\text{Peak}_{\text{fp8}}$ | $1.78562 \times 10^{15}$ | FLOP/s (1,785.62 TFLOP/s) |
| BF16 Peak Compute | $\text{Peak}_{\text{bf16}}$ | $8.92809 \times 10^{14}$ | FLOP/s (892.809 TFLOP/s) |
| HBM Bandwidth | $\text{BW}_{\text{HBM}}$ | $3.3649 \times 10^{12}$ | Bytes/s (3,364.9 GB/s, decimal) |
| HBM Capacity | $C_{\text{HBM}}$ | $96.0$ | GiB |
| Chip-to-Chip ICI Bandwidth | $\text{BW}_{\text{ICI}}$ | $88.66 \times 1024^3$ | Bytes/s per link (88.66 GiB/s, binary) |
| ICI Links per Direction | $L$ | $12$ | `2x2x2` 3D torus bidirectional links |
| Chiplet-to-Chiplet D2D Bandwidth | $\text{BW}_{\text{D2D}}$ | $6.00 \times 10^{11}$ | Bytes/s (600 GB/s, unidirectional), intra-package |
| Inter-Chip Hop Latency | $t_{\text{hop}}$ | $1.3 \times 10^{-6}$ | s (0.0013 ms) |
| Min MXU Contracting Dim | $D_{\text{min}}$ | $256$ | Hardware padding boundary |
